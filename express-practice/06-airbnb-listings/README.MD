# 🏡 06-airbnb-listings

A mini Airbnb-inspired listing application built using Express.js, EJS, and Tailwind CSS.

This project is a continuation of the previous **05-dynamic-ui-ejs** project. In the previous project, the focus was on learning EJS basics, server-side rendering, dynamic data rendering, loops, conditionals, and creating reusable partials. This project extends those concepts by building a more realistic Airbnb-style listing interface with richer data and improved UI design.

## 📌 What's New in This Project

### Reusable UI Components

* Continued using EJS Partials for:

  * Head Section
  * Navigation Bar
  * Hero Section
* Improved overall code organization and maintainability.

### Enhanced Home Registration Form

Added additional fields to collect more listing information:

* Home Name
* Price Per Night
* Location
* Rating
* Photo URL

### Improved Registered Homes Section

The Registered Homes section was redesigned from a simple text-based list into visually appealing Airbnb-style listing cards.

Each card now displays:

* Property Image
* Home Name
* Location
* Rating
* Price Per Night

### UI Improvements

* Responsive card grid layout
* Better spacing and alignment
* Consistent Airbnb-inspired color theme
* Hover effects and shadows for cards
* Improved typography hierarchy
* Custom Success Page after registration
* Custom 404 Error Page

### EJS Concepts Practiced

* Dynamic Data Rendering
* Conditional Rendering
* Looping through Collections
* Reusable Partials
* Dynamic Card Generation
* Passing Data from Routes to Views
