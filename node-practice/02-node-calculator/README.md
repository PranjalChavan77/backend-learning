# Node.js Calculator (Practice Project)

A simple Node.js project built using the core `http` module.

## Features
- Home page with navigation link.
- Calculator page with two input fields.
- Handles form submission via POST request.
- Parses incoming request body manually.
- Uses a separate module for addition logic.
- Displays the calculated sum on a result page.

## Purpose
Practice project to understand:
- HTTP server in Node.js
- Routing using req.url and req.method
- Parsing form data (streams + Buffer)
- Separating logic into modules

## How to run
- Open in browser at: http://localhost:3000
